功能

▸

批量下载

支持 1-8 个任务并行下载，断点续传，格式 / 分辨率 / HDR 可选，完成后自动打开输出文件夹。

▣

格式解析

异步解析视频格式列表，一键批量切换全局分辨率，优先帧率与 HDR 偏好。

⚙

本地转码

多容器与编码矩阵（H.264 / HEVC / VP9 / AV1），自动识别 ffmpeg 可用编码器，支持停止 / 删除任务。

⌁

硬件感知

自动检测 NVIDIA 驱动版本，下载 ffmpeg 时选择兼容构建，避免 NVENC 驱动版本不匹配。

使用方法

第一步在「设置 - 依赖检测」下载安装 yt-dlp 与 ffmpeg
第二步下载页粘贴视频链接，选择清晰度后开始下载
第三步会员内容先在浏览器登录，再到设置选择「Cookie 来源」
第四步转码页添加本地文件，选择容器 / 编码后一键转换
下载 VideoDownloader.exe
