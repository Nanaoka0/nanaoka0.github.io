⬇ VideoDownloader

当前版本 0.1.0-alpha

Windows 桌面视频下载与转码工具，单文件免安装，基于 yt-dlp 与 ffmpeg。

  • ✔ 粘贴链接一键下载，支持多任务并行与播放列表展开
  • ✔ 本地视频转码（MP4 / MKV / WEBM / MOV，CPU 或 GPU 硬件加速）
  • ✔ Cookie 登录态复用，可下载会员 / 登录后内容
  • ✔ HTTP(S) / SOCKS5 代理支持与网络连通测试
下载 VideoDownloader.exe
单文件免安装，直接点击下载即可运行。依赖工具（ffmpeg / ffprobe / yt-dlp）首次运行时在软件「设置 - 依赖检测」中自动下载。
